# Buildmesh v1.4.1

<!-- Audience: Buildmesh users. Lifecycle: draft before the matching tag is published; historical release record afterward. -->

_2026-10-13 — 1 commit since v1.4.0_

v1.4.1 is a **distribution** release. The native Android client now ships as a signed APK beside the Windows installers, so you can download it from the release instead of building it from source. There are no changes to the Windows app itself.

---

## Highlights

- **Signed Android APK on every release.** The release now carries `Buildmesh_1.4.1_android.apk` and a `Buildmesh_1.4.1_android.apk.sha256` checksum file. The APK is signed with a developer-owned release key, not the debug key, and its version matches the Windows installer: `1.4.1`.
- **The Android version is real.** The APK used to report a hardcoded `1.0.0` (version code `1`). It now reads its version from the same place as the desktop app, so Android can tell a newer APK from an older one.

---

## Upgrade notes

- **Android is a sideload.** Download the APK, check it against the `.sha256` file, and install it. Android updates by installing a newer APK over the old one; every release from now on is signed with the same key, so updates install in place. An APK you built yourself from source is signed with a different key, so Android will refuse to update it in place: uninstall it first.
- **Windows is unchanged.** The in-app auto-updater offers v1.4.1 to existing installs as usual. The APK is deliberately **not** part of the updater feed (`latest.json`), which stays Windows-only.
- **Checksums.** `SHA256SUMS.txt` still covers the Windows installers only; the APK carries its own `.sha256` file.
