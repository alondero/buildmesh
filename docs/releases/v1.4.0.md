## Fixes

### Circuit watchdog fails fast on never-observed agents (#1791)

A Circuit step whose agent looks busy but has produced neither a session identity
nor a readable report is now ended after 15 minutes with an explicit reason —
"agent produced no session identity or report within 15 minutes — inspect the
agent terminal" — instead of holding the run for the full 120-minute active-wait
budget. The watchdog still grants the long budget once any progress is observed
(including a session identity captured later), approval gates keep their own
behaviour, and a step that pins its own `timeout_seconds` keeps that budget in
full — the 15-minute fast fail applies only to steps left on the default windows.

### Review circuits are gated on harness capability

The title-bar **Review** control on an Agent Node is now disabled when that
node's harness cannot report its own turn completion — it has neither an
attention hook nor a passive turn watcher. The same harnesses are no longer
selectable as the reviewer in the Start Review dialog or in Settings →
Providers; they stay visible in those pickers, greyed out and labelled
`(no review support)`, so the limitation is discoverable rather than silent.

Because Buildmesh cannot tell when such a harness has finished a turn, a review
Circuit started on one did not fail fast — it waited for a verdict that could
never arrive until its watchdog budget expired. The affected harnesses today are
**Cline**, **Freebuff**, and **DeepSeek Harness**; **Terminal** was already
excluded as a plain shell.

Authored Circuits are unaffected: they carry their reviewer provider in the
graph and can still be built with any harness.

### Review verdicts no longer need the classifier CLI (#1815)

A review Circuit previously parked its verdict gate until the wait budget
expired when the classifier backend was missing, so a Mesh without the `claude`
binary could never reach approval. A reviewer that finishes its turn cleanly
(`ready`/`completed`) with a written report still consults the live classifier
first; only when that backend is absent or fails does the gate fall back to
reading the report's explicit verdict — an approval completes the review,
requested changes start a fix round, and a blocked or ambiguous report parks
visibly for attention. A live classifier verdict is never overridden.
