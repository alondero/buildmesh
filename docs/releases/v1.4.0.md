## Circuits

- **Unobservable circuit agents fail fast instead of burning two hours (#1791)** — a Circuit step whose agent looks busy but has produced neither a session identity nor a readable report is now ended after 15 minutes with an explicit reason — "agent produced no session identity or report within 15 minutes — inspect the agent terminal" — instead of holding the run for the full 120-minute active-wait budget. The watchdog still grants the long budget once any progress is observed, approval gates keep their own behaviour, and an explicit per-step timeout continues to override the defaults.
