## Circuits

- **A review that yields mid-work waits instead of failing.** A review whose reviewer yields while it is still working — a background test run, or an intermediate progress note rather than its findings — used to be read as an incomplete review: the `verdict` step recorded that progress line as the reviewer's report and ended the run **failed** with **Review needs attention**. The `verdict` step now confirms the reviewer has finished its turn before it treats a report as the reviewer's verdict, so the run waits for the reviewer's real findings. An explicit request for input (a permission prompt or question) is still a real outcome, a report the reviewer did finish is still judged exactly as before, and a reviewer that never reports again is bounded by the reviewer's existing wait deadline.
