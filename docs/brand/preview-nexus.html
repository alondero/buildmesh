Nexus · round 2

Buildmesh — Nexus, bolder & token-pure

Three takes on the Nexus badge you picked, rebuilt to two constraints: every colour is now an app token, and the mark is heavier so it holds up at a distance.

  • Colour reverted to the token set only — the old mark used generic Tailwind shades (#22d3ee, #34d399, #a78bfa, #7dd3fc, #4ade80) that exist nowhere in App.css.
  • Wires 2.5 → 5.5, node radii 5 → 8.5, ring 1.5 → 2.5.
  • Dropped the two 1.5px closure arcs and the glow — both were noise at small sizes.
  • Colour count down from 5 to 3, so the mark stays legible when it shrinks.
